# Capstone — End-to-End Machine Learning Project

An academic capstone project demonstrating a complete end-to-end machine learning pipeline. Covers data ingestion, preprocessing, model training, evaluation, and presentation — applied to a real-world dataset.

---

## Contents

| File | Description |
|------|-------------|
| `02_end_to_end_machine_learning_project.ipynb` | Full ML pipeline in a Jupyter notebook |
| `Capstone_Presentation.pdf` | Slide deck summarizing the project, methodology, and results |

---

## What's Covered

- Data loading and exploration
- Feature engineering and preprocessing
- Model selection and training
- Evaluation metrics and results
- Insights and next steps

---

## Tech Stack

- **Python 3**
- **Jupyter Notebook**
- **Pandas** — Data manipulation
- **Scikit-learn** — Machine learning models
- **Matplotlib / Seaborn** — Data visualization

---

## How to Run

1. Install dependencies:
```bash
pip install pandas scikit-learn matplotlib seaborn jupyter
```
2. Open the notebook:
```bash
jupyter notebook 02_end_to_end_machine_learning_project.ipynb
```

This project was completed as part of an academic program to demonstrate proficiency in applied machine learning and data science workflows.
